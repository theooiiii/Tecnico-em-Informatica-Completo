# Módulo 02 — Hardware e Manutenção

> "Conhecer o hardware é compreender como um computador realmente funciona."

---

# 📖 Sobre este módulo

Neste módulo serão estudados os componentes físicos do computador, sua arquitetura, funcionamento, montagem, diagnóstico de problemas e manutenção preventiva.

Ao final deste módulo o aluno será capaz de identificar praticamente todos os componentes internos de um computador, compreender seu funcionamento e realizar procedimentos básicos de manutenção.

---

# 🎯 Objetivos

Ao concluir este módulo você será capaz de:

- Identificar todos os componentes internos de um computador.
- Entender como os componentes se comunicam.
- Escolher peças compatíveis.
- Montar um computador.
- Diagnosticar problemas comuns.
- Realizar manutenção preventiva.
- Entender conceitos de desempenho.
- Interpretar especificações técnicas.
