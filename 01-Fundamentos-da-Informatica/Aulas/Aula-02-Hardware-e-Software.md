# Introdução

Quando observamos um computador, enxergamos apenas parte do que realmente faz o sistema funcionar. Um computador depende de dois elementos inseparáveis: **hardware** e **software**.

O hardware corresponde à parte física, composta pelos componentes eletrônicos e mecânicos. Já o software representa a parte lógica, formada pelos programas e instruções que controlam o funcionamento do equipamento.

Nenhum computador funciona apenas com hardware ou apenas com software. Ambos trabalham em conjunto para executar tarefas, armazenar informações e permitir a interação entre o usuário e a máquina.

Nesta aula, conheceremos detalhadamente esses dois conceitos fundamentais da informática.

---

# O que é Hardware?

Hardware é todo componente físico de um sistema computacional.

É tudo aquilo que pode ser visto e, na maioria dos casos, tocado.

Exemplos:

- Processador (CPU)
- Memória RAM
- Placa-mãe
- SSD
- HD
- Fonte de alimentação
- Placa de vídeo
- Monitor
- Mouse
- Teclado
- Impressora
- Webcam
- Caixa de som

Sem o hardware, não existe equipamento capaz de executar programas.

# O que é Software?

Software é a parte lógica do computador.

É o conjunto de programas, instruções e dados que orientam o hardware sobre o que deve ser feito.

Um software não pode ser tocado fisicamente, mas pode ser instalado, executado, atualizado ou removido.

Sem software, um computador ligado seria apenas um conjunto de componentes eletrônicos incapazes de realizar qualquer tarefa útil.

---

Exemplos:

---

# Firmware

Firmware é um tipo especial de software gravado diretamente em componentes eletrônicos.

Ele controla o funcionamento básico do equipamento.

Exemplos:

- BIOS
- UEFI
- Firmware de roteadores
- Firmware de SSD
- Firmware de impressoras

O firmware normalmente permanece armazenado em memória não volátil e continua disponível mesmo após desligar o equipamento.

---

# Relação entre Hardware e Software

Hardware e software trabalham de forma integrada.

Exemplo:

O usuário pressiona uma tecla.

↓

O teclado envia um sinal elétrico.

↓

O sistema operacional interpreta esse sinal.

↓

O programa recebe a informação.

↓

O texto aparece na tela.

Nenhuma dessas etapas aconteceria sem a colaboração entre hardware e software.

# Glossário

**Hardware** — Parte física de um sistema computacional.

**Software** — Conjunto de programas e instruções que controlam o hardware.

**Firmware** — Software gravado diretamente em um dispositivo eletrônico.

**Sistema Operacional** — Software responsável por gerenciar os recursos do computador.

**Driver** — Software que permite ao sistema operacional comunicar-se corretamente com um dispositivo de hardware.
