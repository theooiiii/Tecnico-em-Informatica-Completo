# Introdução

Vivemos em uma sociedade movida por informações. Todos os dias produzimos milhares de dados ao utilizar celulares, computadores, cartões bancários, redes sociais, sistemas de saúde e plataformas digitais.

Entretanto, computadores não compreendem o significado das informações como os seres humanos. Eles recebem dados, executam instruções e geram resultados.

Entender a diferença entre dado, informação e conhecimento é fundamental para qualquer profissional da área de tecnologia.

Essa distinção está presente em praticamente todas as áreas da informática, como bancos de dados, inteligência artificial, ciência de dados, segurança da informação e desenvolvimento de sistemas.

---

# O que é um Dado?

Um dado é um elemento bruto, isolado e sem contexto.

Ele representa um valor, número, palavra, símbolo ou registro que, sozinho, não possui significado suficiente para apoiar uma decisão.

Exemplos:

```
25

João

R$ 2.350,00

15/08/2026

Aprovado
```

Todos esses exemplos são apenas dados.

Sem contexto, não sabemos exatamente o que representam.

---

# Características dos Dados

Os dados podem ser:

- Numéricos
- Textuais
- Alfanuméricos
- Binários
- Visuais
- Sonoros

Exemplos:

| Tipo | Exemplo |
|------|----------|
| Número | 120 |
| Texto | Maria |
| Data | 10/01/2026 |
| Imagem | Foto |
| Áudio | Gravação |
| Vídeo | Filmagem |

---

# O que é Informação?

Informação é um conjunto de dados organizados, interpretados e contextualizados.

Quando os dados recebem significado, tornam-se úteis para quem os utiliza.

Exemplo:

Dados:

```
João

18 anos

Aprovado
```

Informação:

```
João foi aprovado no curso e possui 18 anos.
```

Agora existe contexto.

Existe significado.

Existe compreensão.

---

# Características da Informação

Uma boa informação deve ser:

- Correta
- Atualizada
- Completa
- Relevante
- Confiável
- Fácil de compreender

Quanto maior a qualidade da informação, melhores serão as decisões tomadas.

---

# O que é Conhecimento?

Conhecimento é a capacidade de interpretar informações e utilizá-las para resolver problemas ou tomar decisões.

Enquanto o computador trabalha principalmente com dados e informações, o ser humano agrega experiência, interpretação e raciocínio.

Exemplo:

Informação:

```
Paciente apresenta temperatura de 39°C.
```

Conhecimento:

O médico interpreta essa informação, avalia outros sintomas e define o tratamento adequado.

---

# Relação entre Dado, Informação e Conhecimento

```
DADOS
 ↓
Organização
 ↓
INFORMAÇÃO
 ↓
Análise
 ↓
CONHECIMENTO
 ↓
Decisão
```

Essa sequência está presente em praticamente todos os sistemas computacionais modernos.

# O Ciclo de Processamento da Informação

Todo computador executa um ciclo básico de processamento.

```
┌──────────┐
│ Entrada  │
└────┬─────┘
     │
     ▼
┌──────────────┐
│Processamento │
└────┬─────────┘
     │
     ▼
┌──────────────┐
│Armazenamento │
└────┬─────────┘
     │
     ▼
┌──────────┐
│  Saída   │
└──────────┘
```

---

# Entrada

É o momento em que os dados chegam ao computador.

Exemplos:

- Teclado
- Mouse
- Scanner
- Webcam
- Microfone
- Sensores

---

# Processamento

Os dados são analisados pela CPU seguindo as instruções dos programas.

Durante essa etapa são realizados milhões ou bilhões de cálculos por segundo.

---

# Armazenamento

Após o processamento, os dados podem ser armazenados.

Exemplos:

- SSD
- HD
- Pen Drive
- Banco de Dados
- Nuvem

---

# Saída

O computador apresenta os resultados ao usuário.

Exemplos:

- Monitor
- Impressora
- Alto-falantes
- Projetor

---

# A Importância da Qualidade dos Dados

Existe um princípio muito conhecido na computação:

> **Garbage In, Garbage Out (GIGO)**

Tradução:

**"Se a entrada for lixo, a saída também será lixo."**

Isso significa que um sistema não consegue produzir informações corretas utilizando dados incorretos.

Exemplo:

Se um funcionário cadastrar um preço errado em um sistema, todas as vendas utilizarão esse valor incorreto.

# Glossário

**Dado** — Valor bruto sem contexto.

**Informação** — Dados organizados e interpretados.

**Conhecimento** — Capacidade de utilizar informações para resolver problemas e tomar decisões.

**Processamento** — Execução de operações sobre dados.

**GIGO** — Princípio que afirma que dados incorretos geram resultados incorretos.
