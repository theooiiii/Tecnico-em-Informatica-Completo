# 🖥️ Aula 02 — Hardware e Software

> Entenda os componentes físicos e lógicos de um computador, como eles trabalham em conjunto e por que ambos são indispensáveis para o funcionamento dos sistemas computacionais.

---

## 📚 Sobre esta Aula

Nesta aula você aprenderá os conceitos fundamentais de **hardware** e **software**, conhecerá os principais componentes de um computador, entenderá como ocorre a comunicação entre eles e desenvolverá as bases necessárias para disciplinas como manutenção, sistemas operacionais, redes de computadores e infraestrutura.

Ao final, você será capaz de identificar componentes físicos, reconhecer diferentes tipos de software e compreender como um computador executa suas tarefas.

---

# 🎯 Objetivos de Aprendizagem

Ao concluir esta aula, você será capaz de:

- Definir hardware e software.
- Diferenciar componentes físicos e programas.
- Identificar os principais componentes de um computador.
- Compreender a função de cada componente.
- Entender como hardware e software trabalham em conjunto.
- Reconhecer dispositivos de entrada, saída e armazenamento.
- Aplicar boas práticas de utilização e manutenção.
- Desenvolver raciocínio para diagnóstico básico de problemas.

# 📋 Resumo

Nesta aula você estudará os conceitos fundamentais de hardware e software, compreenderá como os componentes físicos e os programas trabalham em conjunto e desenvolverá uma base sólida para os próximos módulos do curso.

Esse conhecimento é indispensável para qualquer profissional da área de Tecnologia da Informação e servirá como fundamento para disciplinas como sistemas operacionais, manutenção, redes, infraestrutura, segurança da informação e desenvolvimento de software.

> [!TIP]
> Não memorize apenas os nomes dos componentes. Procure entender **qual é a função de cada um** e **como eles interagem** durante o funcionamento do computador. Esse entendimento será essencial para os conteúdos mais avançados do curso.
