# Módulo 01 — Fundamentos da Informática

## Sobre este módulo

Este é o primeiro módulo do curso **Técnico em Informática**.

Aqui serão apresentados os conceitos fundamentais da informática, formando a base para todos os demais módulos do curso.

Ao concluir este módulo, o estudante compreenderá como um computador funciona, quais são seus principais componentes e os conceitos essenciais utilizados ao longo da formação.

---

# Objetivos

Ao finalizar este módulo, o aluno será capaz de:

- Compreender o conceito de informática;
- Diferenciar hardware e software;
- Entender como ocorre o processamento de dados;
- Conhecer os principais componentes de um computador;
- Identificar diferentes tipos de armazenamento;
- Trabalhar com arquivos e pastas.
